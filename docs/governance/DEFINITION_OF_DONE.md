# Definition of Done
المهمة done عندما deliverables ضمن scope، requirements موصولة، acceptance قابلة للرصد مثبتة، قراراتها المعتمدة مرفقة، ومراجع مستقل راجعها. passing unit tests وحدها لا تعني قبول المنتج.

يلزم permission/masking/negative transitions/audit tests؛ finance/stock transactions وraces/idempotency/reversal عند الصلة؛ migrations forward/rollback آمنة؛ RTL keyboard/mobile evidence؛ reconciled reports وfreshness؛ monitoring/runbook/backup impact؛ AI evaluations/failure/human review عند الصلة. وثّق كل check exact command وexit ووقت وبيئة وartifact؛ skipped مع السبب ليس passed.

لكل increment demo وevidence index وproduct owner sign-off وقرارات مغلقة عند بوابتها. كل AT-01..AT-15 يملك test/evidence وربطاً بالمصدر. لا يُقبل deferred على أنه منجز ولا numeric SLO مفترض. الحزمة الحالية planning فقط ولا تدعي تطبيق هذه الضوابط.
