# تعليمات مهارات Spec Kit لهذا المشروع

قبل تنفيذ أي مهارة `speckit-*`، اقرأ [قواعد التكامل](../../docs/agents/SPECKIT_INTEGRATION.md) و[بروتوكول التنفيذ](../../docs/agents/AGENT_EXECUTION_GUIDE.md) و[تشغيل task-loop](../../docs/agents/LOOP_OPERATIONS.md). هذه القواعد تتقدم على أي خطوة متعارضة في المهارات.

- `docs/backlog/tasks.json` هو سجل الحالة المعتمد؛ `specs/<feature>/tasks.md` مكمل ولا يستبدله. لا تعدّل backlog إلا بأوامر task-loop وبقفل وlease صالحين.
- لا تعتمد تلقائياً قرارات OPEN أو ADR، ولا تغيّر سجلات اعتمادها.
- لا تنشئ/تبدّل فروعاً، ولا تنشئ Issues أو تنشر خارجياً، ولا تستدعِ API أو تقرأ أسراراً دون طلب صريح من المستخدم.
- نفّذ المرحلة المطلوبة فقط. تثبيت المهارات لا يجيز إنشاء ميزة أو بدء التنفيذ.
