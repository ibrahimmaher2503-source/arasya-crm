## الخيار المعتمد ضمن موافقة Product

Approved option: Structured Laravel modular monolith، بتطبيق واحد قابل للنشر وحدود ownership صريحة. لكل aggregate مالك كتابة واحد؛ والتفاعل بين modules عبر Application contracts محددة النطاق وموثوقة، أو أحداث بعد commit للآثار اللاحقة. تُمنع الكتابة العشوائية إلى جداول module آخر، والنماذج التجارية المشتركة القابلة للتغيير، والاعتماديات الدائرية. تقبل الموافقة كلفة الترابط المتبقية وshared deployment/schema وما يصاحبهما من مخاطر coupling ووحدة عطل أو توسع مشتركة، مقابل تجنب التعقيد والتوزيع المبكرين لـmicroservices دون حاجة مثبتة. لا تُلزم هذه الموافقة runtime أو package أو stack بعينه.

## النطاق والحدود

القبول يخص الخيار التصميمي في ADR-001 فقط، بما يشمل ownership وحدود modules وعقود Application المحددة النطاق والأحداث الموثوقة بعد commit والمفاضلات المعمارية الموثقة. لا يعتمد runtime أو package أو قاعدة بيانات أو queue أو hosting، ولا ADR-002 أو ADR-003 أو أي ADR آخر، ولا يغلق أي `OPEN-*` policy، ولا يمنح موافقة إنتاج أو تنفيذ أو إذناً بإنشاء commit. لا يغيّر بذاته task status أو dependencies؛ إعادة تقييم المنسق منفصلة.
